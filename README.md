# Markdown WYSIWYG Editor

Open Markdown files with an editable rich-text custom editor. The file remains Markdown on disk.

Uploaded images are copied next to the Markdown file and inserted as relative links, so the document stays filesystem-backed instead of using temporary blob URLs.

Use the explorer context menu or command palette command:

```text
Markdown WYSIWYG: Open Editor
```

This is a clean-room VS Code extension implementation. It does not copy Cursor's internal workbench code.
